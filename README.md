# VARIO Local Link

VARIO Local Link verbindet Deine VARIO Cloud mit Geräten und Dateien in Deinem lokalen Netzwerk. Der Dienst kann zum Beispiel Belege und Etiketten drucken, Dateien übertragen sowie Kartenterminals und Waagen anbinden.

## Download für Windows

Öffne die aktuelle stabile Version und lade unter **Assets** die Datei **`VARIO-Local-Link-Installation.exe`** herunter. [Zu den GitHub Releases](https://github.com/vario-software/local-link/releases)

Die automatisch erzeugten Archive **Source code (zip)** und **Source code (tar.gz)** enthalten die Dateien dieses Download-Repositories.

## Installation und Einrichtung

Du brauchst einen Windows-PC mit Zugriff auf die Geräte und Ordner, die Du anbinden möchtest. Außerdem brauchst Du Zugang zu einer VARIO-Cloud-Installation, die Du im Rahmen eines laufenden VARIO-Cloud-Vertrags nutzen darfst.

1. Führe die heruntergeladene `.exe` aus und folge dem Installationsassistenten.
2. Öffne anschließend VARIO Local Link im Browser. Beim Standardport lautet die Adresse `http://localhost:8088`.
3. Verbinde unter **Einstellungen → Installationen** Deine VARIO-Cloud-Installation. Dafür benötigst Du einen Local-Link-Benutzer und die Zugangsdaten eines API-Clients aus dem Admin-Center. [Anleitung zur Installation und Einrichtung](https://help.vario-software.de/vario-cloud-handbuch/grundlagen-und-konzepte/vario-local-link/installation-und-einrichtung)

Der Rechner und der Local-Link-Dienst müssen laufen, solange Du die angebundenen Funktionen nutzt.
